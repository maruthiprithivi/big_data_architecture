    This is an analytics agent with bounded tools. It does not run arbitrary code or train a recommender. The model chooses a query plan; the app validates it, executes SQL, returns evidence to the model, and builds an HTML artifact.

    Know what these data can say.

    All 1,000,000 sessions are synthetic, with four movie titles, two device types and ten fixed event dates. Each row is one session. Watch time is either 60 or 1,800 seconds. Changing 20 to 30 minutes leaves the engaged set unchanged; 40 minutes yields zero engaged sessions.

    There is no random assignment, equal exposure, unique-viewer count or satisfaction label. Return visits and quick exits are proposed experiment measures, not measured gains. The timestamps illustrate event time and ingestion time; no live source is streaming into this lab.

    No API key. After the first model download, inference and queries stay in the local Compose stack. First start needs internet and Docker Desktop; allow several minutes. If setup is blocked, use the lecture’s browser-only lab.

    Module connection: ingestion contract → typed column storage → aggregate query → dashboard → decision → next measurement.
